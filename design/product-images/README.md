# B站私人编排器 · 商品图套卡

小红书 3:4 套图，6 张，1080 × 1440 PNG。

## 出图

```bash
./render.sh
```

用 headless Chrome 以 2 倍像素密度渲染（2160 × 2880），再用 `sips` 降采样回 1080 × 1440，
文字边缘比直接按 1080 渲染更干净。产物在 `out/`。

改文案直接改 `p*.html`；改全局样式改 `card.css`。改完重跑 `./render.sh`。

## 6 张牌分别干什么

| 文件 | 作用 |
|---|---|
| `p1.png` | 封面。B站粉满版，主标题 + 一条填好的七天周条 |
| `p2.png` | 为什么需要。「自己挑 6 步」对「说一句 3 步」 |
| `p3.png` | 为什么好用。自然语言 / 个性化过滤 / 自动编排 |
| `p4.png` | 三个示例。每句下面列出它解析出的条件标签 |
| `p5.png` | 怎么获取。三步流程 + 收尾 |
| `p6.png` | 三个常见疑问 |

## 设计令牌

**色彩**

| 名字 | 值 | 用途 |
|---|---|---|
| paper | `#F5F6F8` | 内页底色（冷调纸白，不用米白） |
| ink | `#14161F` | 正文与标题 |
| pink | `#FB7299` | 主强调、封面底色（B站粉） |
| pink-deep | `#BC2F5B` | 粉色小字，保证在浅底上的对比度 |
| blue | `#0090C0` | 示例编号等次级标记（B站蓝） |
| mute | `#7C828F` | 次要说明文字 |

**字体**

- 标题、序号、引言：`Songti SC`（宋体）。大字号下的印刷感，避开 AI 商品图清一色的无衬线。
- 正文：`PingFang SC`。两个字族差异明显，不混用第三个。

**版式**

1080 × 1440，左右边距 88px，全部左对齐。标题 78px、正文 32–35px、页脚 24px。
不用圆角卡片、柔灰阴影、渐变、全大写标签、`01 / 02 / 03` 编号。

**唯一的大胆之处**

封面底部那条七天周条：七个格子里真的填着一周的编排结果，「四」被填成墨色块表示今天。
整个套卡的视觉语言都从产品自己的产出物（一份排期表）里来，而不是从电商模板里来。

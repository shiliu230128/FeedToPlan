# 开始之前，告诉我你想要什么

你可以用自然语言直接说，或者参考下面的场景示例。说得越具体，编排越贴合你。

---

## 典型场景示例

### 运动跟练
> 我想要一个本周瑜伽跟练计划。我每天早上有 30 分钟，目标是缓解久坐肩颈和腰背问题，瑜伽练了大约半年，膝盖不太好不适合深蹲。

> 帮我做一份居家健身计划。女生，体重 65kg，目标减脂，每周能练 4 天，每次 40-50 分钟，无器械，有一定运动基础。

### 冥想 / 压力缓解
> 最近工作压力大，睡眠不好。想要一些冥想或放松类内容，10-20 分钟就好，睡前能直接拿来用。

### 轻音乐 / 背景音
> 整理一份本周学习工作时的背景音乐，偏轻音乐和白噪音，不要有歌词，时长越长越好，从我关注的音乐 UP 里选。

### 自定义主题（通用格式）
> 我想要一份关于 [主题] 的本周内容安排。[说明目标 / 当前状态 / 身体限制 / 每天可用时间]。来源用 [关注的UP / 全站搜索 / 都要]。

---

## 系统会从你的描述里提取

- 主题和关键词
- 每天可用时长（duration_min / duration_max）
- 目标和偏好（减脂 / 放松 / 力量 / 入睡等 → notes 字段注入 prompt）
- 需要回避的内容（膝盖限制 / 不要跳跃 / 不要歌词等 → notes 字段）
- 内容来源（关注列表 / 全站 / 混合 → scope）

---

## 如果用户只说了一个关键词

先问以下几个问题再开始：

1. 每天能投入多少时间？（用来设定 duration_max）
2. 这次的目标是什么？（减脂 / 放松 / 增强柔韧性 / 睡眠改善 / 纯欣赏等）
3. 有没有需要回避的内容类型或身体限制？
4. 从关注列表里选，还是全站搜索，还是都要？

收到回答后，组合成一个自然语言摘要写入 notes，然后调用 CLI。
